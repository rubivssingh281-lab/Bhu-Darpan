# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 1.0.x | :white_check_mark: |
| < 1.0 | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability within Bhū-Darpan, please send an email to the repository maintainer. 

Please **do not** open public GitHub issues for security vulnerabilities. All reports will be investigated promptly.
